# 📊 Netflix Analysis — Exploratory Data Analysis with Python

This project presents an Exploratory Data Analysis (EDA) of Netflix's publicly available dataset. The objective is to understand the content distribution, trends, and insights related to Netflix's shows and movies.

---

## 📁 Dataset

The dataset contains information about Netflix content such as:
- Title
- Type (Movie or TV Show)
- Director, Cast
- Country of origin
- Date added to Netflix
- Release year
- Rating
- Duration
- Genre (listed in "categories" column)

---

## 🛠️ Tools & Libraries Used

- **Python**
- **Jupyter Notebook**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**

---

## 🔍 Key Insights

- Distribution between Movies and TV Shows on Netflix
- Most frequent genres/categories
- Content production trend over the years
- Top contributing countries
- Common release years
- Rating distribution across content types
- Word cloud of most common titles and cast members
